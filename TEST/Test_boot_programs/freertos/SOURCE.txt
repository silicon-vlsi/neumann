Port notes for the neumann core:
  - mtime/mtimecmp: Wally CLINT, 0x0200_BFF8 / 0x0200_4000, mtime counts every clock.
  - "csrs mie" in xPortStartScheduler: the core has no mie CSR; unknown CSRs read 0 and
    ignore writes (no trap), so this is a no-op. Interrupts are gated by mstatus.MIE and at
    the source (mtimecmp), which is what the port relies on.
  - The core traps vectored (interrupt n -> mtvec + 4n, exceptions -> mtvec + 0x84/0x88/0x8C).
    programs/rtos/start_rtos.S puts "j freertos_risc_v_trap_handler" in every vector; the
    handler dispatches on mcause.
